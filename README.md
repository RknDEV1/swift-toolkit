# Swift Toolkit

A clean collection of reusable **Swift** and **SwiftUI** utilities for native iOS development.

## Goals

- Small, focused and well-tested utilities
- Clear documentation
- Ready to use via Swift Package Manager
- No unnecessary complexity

## Requirements

- iOS 16+
- Swift 5.9+
- Xcode 15+

## Installation

### Swift Package Manager

Add the package to your `Package.swift` or via Xcode:

```swift
.package(url: "https://github.com/RknDEV1/swift-toolkit.git", from: "1.0.0")
```
