# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-10-30

### Added
- String and Optional extensions
- Secure Keychain helper
- Type-safe UserDefaults
- Email and CPF validators
- Currency and number formatters (pt-BR)
- Date helpers and relative formatting
- Haptic feedback helpers (iOS only)
- Lightweight NetworkClient
- LoadingView and EmptyStateView
- View extensions
- Initial CI and documentation
